Устранение вылезания плашки даты на мобильных устройствах

В веб-браузерах на телефонах инпуты типа date по умолчанию имеют браузерный стиль WebKit с внутренними системными отступами и фиксированными размерами. При отсутствии строгой модели box-sizing: border-box такой инпут выталкивал правый край за границу персиковой плашки.

✕ Было (с вылезанием)
Инпут даты распирал плашку вправо на 14–18 px. Правый отступ срезался, и модалка получала паразитный горизонтальный скролл.
/* Было в коде */
input[type="date"] {
  /* box-sizing не задан */
  width: 100%;
  /* системный WebKit padding */
}
Переполнение: scrollWidth > clientWidth (+16px)
✓ Стало (идеальная геометрия)
Поле даты строго удерживается внутри персиковой плашки. Ширина ровно совпадает с полем суммы и заметки, правый отступ ровно 16 px.
/* Строгое исправление v2 */
.golden-field-group {
  width: 100%; box-sizing: border-box; min-width: 0;
}
input[type="date"].inc-pay-date {
  width: 100% !important; max-width: 100% !important;
  box-sizing: border-box !important; min-width: 0 !important;
  -webkit-appearance: none; appearance: none;
}
Переполнение: scrollWidth (358px) == clientWidth (358px) (0 px)
📐
Фактический замер геометрии в данном фрейме:
Ширина модалки: 358 px | Ширина инпута суммы: 326 px | Ширина инпута даты: 326 px.
Разница между шириной поля суммы и даты: 0.00 px (100% идентичность).
